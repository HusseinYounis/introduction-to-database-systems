TEACHING STRATEGIES AND METHODS

Student-centered and active learning strategies will be utilized to accomplish the outlined student learning outcomes:

  • Lectures: Interactive sessions involving concept explanations, live SQL demonstrations, case studies, and discussions on real-world database architectures.
  • Readings: Students are responsible for reading textbook chapters before class to prepare questions and engage in informed discussions.
  • In-Class Activities: Hands-on schema design, normalization exercises, and collaborative query optimization challenges.
  • Outside-Class Activities: Individual SQL programming assignments and a comprehensive group Database Design Project.

COURSE DETAILS

Course Description

This course provides a comprehensive introduction to the principles, design, and implementation of modern database management systems (DBMS). It begins with foundational concepts of data modeling, including Entity-Relationship (ER) diagrams, and progresses to the relational model, relational algebra, and Structured Query Language (SQL). The course covers database design theory, including functional dependencies and normalization (up to BCNF and 4NF). Advanced topics include transaction management, concurrency control, recovery systems, and an introduction to NoSQL and distributed databases. Through hands-on programming assignments and a capstone design project, students will gain the practical skills to design, implement, and optimize robust database systems for real-world engineering applications.

Course Learning Outcomes (CLOs)

Upon the completion of the course students will be able to achieve the following learning outcomes:

  1. CLO1 – : Explain the role of a DBMS and distinguish it from file-based data management.
  2. CLO2 – : Model real-world requirements using ER and EER diagrams.
  3. CLO3 – : Convert conceptual designs into relational schemas with keys and constraints.
  4. CLO4 – : Write SQL queries for data definition, manipulation, and retrieval.
  5. CLO5 – : Apply normalization theory to reduce redundancy and improve consistency.
  6. CLO6 – : Describe storage structures, indexing, and query processing techniques.
  7. CLO7 – : Explain transaction management, concurrency control, and recovery concepts.
  8. CLO8 – : Compare relational and NoSQL database approaches for different application needs.
